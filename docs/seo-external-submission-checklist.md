# SEO External Submission Checklist

Chinese version: [seo-external-submission-checklist.zh-CN.md](./seo-external-submission-checklist.zh-CN.md)

Use this checklist after deploying SEO Phase 2. The goal is not spammy link building. The goal is to give Google and developer users more legitimate paths to discover `https://jsonfmt.org/`.

## Priority 1: Owned Developer Profiles

| Channel | Target link | Action | Status | Notes |
| --- | --- | --- | --- | --- |
| GitHub profile README | `https://jsonfmt.org/` | Add JSONFmt as a browser-local JSON formatter and error finder. | Not started | Use natural brand anchor text. |
| GitHub project README | `/json-error-finder/` or `/guides/` | Create or update a small JSON examples repository and link to the relevant guide hub. | Not started | Keep examples useful, not promotional only. |
| Personal website or portfolio | `https://jsonfmt.org/` | Add JSONFmt under developer tools or side projects. | Not started | Link from an indexable page. |
| CNB / code hosting profile | `https://jsonfmt.org/tools/` | Add JSONFmt as a public JSON utility. | Not started | Match profile rules. |

## Priority 2: Developer Communities

| Channel | Target link | Action | Status | Notes |
| --- | --- | --- | --- | --- |
| DEV.to | `/guides/unexpected-token-less-than-in-json/` | Publish a short post about APIs returning HTML instead of JSON. | Not started | Include a real debugging checklist. |
| Hashnode | `/guides/json-parse-unexpected-token-u/` | Publish a post about undefined values and JSON.parse. | Not started | Use original examples. |
| Medium | `/guides/is-online-json-formatter-safe/` | Publish a privacy-first JSON formatting article. | Not started | Avoid duplicate full-page copying. |
| Reddit or Stack Overflow profile | `https://jsonfmt.org/` | Add profile link only where allowed. | Not started | Do not post promotional answers. |

## Priority 3: Tool Directories

| Directory type | Target link | Action | Status | Notes |
| --- | --- | --- | --- | --- |
| Developer tool directories | `https://jsonfmt.org/` | Submit JSONFmt as a free browser-local JSON formatter. | Not started | Use unique descriptions per directory. |
| Startup/tool listing sites | `https://jsonfmt.org/tools/` | Submit if the category fits. | Not started | Skip low-quality directories. |
| Privacy-focused tool lists | `/privacy/` and homepage | Pitch the browser-local processing angle. | Not started | Do not overclaim security. |
| Open-source resource lists | `/guides/` | Suggest the JSON error guide library as a learning resource. | Not started | Only submit where useful. |

## Priority 4: Search Console Follow-Up

- Submit `https://jsonfmt.org/sitemap.xml` after deployment.
- Request indexing for the homepage, `/tools/`, core tool pages, and the 20 Phase 2 guide pages.
- Recheck indexing status after 24-72 hours.
- Record impressions, clicks, CTR, and average position weekly in `gsc-monitoring-table.md`.
- If a page has impressions but low CTR, rewrite title and description.
- If a page is crawled but not indexed, improve content uniqueness, internal links, and external discovery.

## Rules

- Do not buy links.
- Do not use private blog networks.
- Do not mass-submit to low-quality directories.
- Do not copy the same article across every platform.
- Do not paste private JSON payloads into public examples.
- Prefer practical debugging posts and useful resource links over promotional posts.
