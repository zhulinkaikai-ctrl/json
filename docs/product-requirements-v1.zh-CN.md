# JSON Error Finder - 产品需求文档（V1）

English version: [product-requirements-v1.md](./product-requirements-v1.md)

## 1. 产品概述

JSON Error Finder 是一个面向开发者的英文、隐私优先型 Web 工具，帮助用户快速诊断无效 JSON。产品是一个单页应用，核心任务是帮助用户在不上传或保存数据的情况下，将无效 JSON 修复为有效 JSON。

主要定位：**JSON Error Finder / Fix Invalid JSON**。

## 2. 问题说明

开发者经常会把 API 响应、日志、配置文件和文档中的 JSON 粘贴到在线工具中。现有格式化工具通常只提示 JSON 无效，或直接展示原始解析器错误信息。它们往往无法清楚说明错误位置、无效原因以及修复方法。

通用 JSON 格式化工具市场竞争激烈。因此，V1 不试图做一个宽泛的 JSON 工具集合，而是通过易读的错误诊断来形成差异化。

## 3. 目标用户和核心任务

**目标用户：** 使用 API 和结构化数据的英语开发者。

**核心任务：** 当开发者拥有无效 JSON 时，帮助其识别语法错误，并在同一个浏览器会话中手动修复。

## 4. V1 解决方案

首页就是工具本身。用户可以粘贴 JSON、直接输入、导入本地 `.json` 文件、将文件拖入编辑器，或加载示例。工具会在短暂防抖后验证输入。

主要界面采用桌面优先的开发者工具布局：

- 用于 JSON 输入和行内错误标记的 Monaco 编辑器。
- 显示当前状态的诊断面板。
- 用于格式化、压缩、复制、清空、加载示例和导入本地文件的紧凑操作栏。

对于无效 JSON，工具会高亮失败位置，并展示英文解释、行号和列号、附近上下文以及手动修复建议。工具不得自动修复或重写无效输入。对于有效 JSON，工具会启用格式化、压缩和复制操作。

## 5. 功能需求

### 输入和验证

- 支持粘贴文本、直接在编辑器中输入、导入 `.json` 文件以及拖放文件导入。
- 只验证严格标准 JSON。
- 输入发生变化后，使用防抖机制进行验证。
- 正常支持最大 10 MB 的输入。
- 超过 10 MB 时显示明确的超大输入状态，并跳过解析。

### 诊断

- 支持 `empty`、`editing`、`valid`、`invalid`、`oversize` 和 `file error` 状态。
- JSON 无效时，在编辑器中标记失败位置。
- 提供行号/列号、英文解释、附近上下文和修复建议。
- 在可能的情况下，对常见错误进行分类：缺少逗号、末尾逗号、字符串未闭合、单引号、注释、对象键未加引号、非法控制字符以及括号不匹配。

### 操作

- 只有 JSON 有效时，才可使用 `Format` 和 `Minify`。
- 当前编辑器存在内容时，`Copy` 可以复制编辑器内容。
- `Clear` 清空编辑器。
- `Load sample` 使用有效示例替换编辑器内容。
- `Import file` 打开本地 `.json` 文件。

## 6. 隐私和分析

JSON 只在浏览器中解析和转换。V1 不上传、存储、同步或分享 JSON 输入，也不提供账户功能。

匿名分析可以记录页面浏览量、输入方式、粗粒度输入大小区间、验证状态、标准化错误类别和操作点击。但绝不能记录 JSON 文本、字段、值、文件名、错误片段、剪贴板内容、用户 ID 或包含用户数据的 URL。

主要匿名成功漏斗为：

`json_invalid_detected -> diagnosis_viewed -> json_became_valid`

## 7. 技术约束

- Vite + React + TypeScript。
- Monaco Editor。
- 部署到 Vercel、Netlify 或 Cloudflare Pages 等静态托管平台。
- 不进行服务端 JSON 解析。
- 不提供账户、数据库或 JSON 持久化层。
- 优先保证桌面浏览器体验。
- 基础移动端可读性是期望项，但不是 V1 的优化目标。

## 8. 非目标

- 账户、云端保存、分享链接和团队协作。
- HTTP 请求、API 环境或 API 客户端功能。
- 自动修复 JSON。
- JSON5 或其他宽松 JSON 模式。
- 树形视图、JSONPath、差异比较、Schema 生成、代码生成、数据转换和多工具导航。
- 广告、赞助提示和付费套餐。

## 9. 成功标准

- 上线后的前 30 天至少获得 100 次英文自然搜索访问。
- 至少 30% 的无效 JSON 会话在展示诊断后从无效变为有效。
- 自动化测试覆盖核心 JSON 诊断、常见错误分类、操作、文件输入限制和超大输入处理。
- 工具绝不传输或存储用户 JSON 内容。
