# Project Documentation

This directory stores product requirements, implementation plans, SEO notes, and operational checklists for JSONFmt.

Every English Markdown document must have a Chinese companion in the same directory with the `.zh-CN.md` suffix. For example:

- English: `product-requirements-v1.md`
- Chinese: `product-requirements-v1.zh-CN.md`

Keep route names, commands, file paths, code blocks, and acceptance criteria aligned between both versions. The Chinese copy is for project reference and does not replace the English copy used for the public website.

`npm test` includes a documentation parity check so new English documents cannot be added without a matching Chinese copy.

Chinese version: [README.zh-CN.md](./README.zh-CN.md)
