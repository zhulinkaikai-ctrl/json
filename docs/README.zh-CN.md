# 项目文档

此目录保存 JSONFmt 的产品需求、实施计划、SEO 说明和运营检查清单。

每份英文 Markdown 文档都必须在同一目录下有一份中文副本，并使用 `.zh-CN.md` 后缀。例如：

- 英文：`product-requirements-v1.md`
- 中文：`product-requirements-v1.zh-CN.md`

两个版本中的路由名称、命令、文件路径、代码块和验收标准必须保持一致。中文版用于项目内部阅读，不替代面向网站公开使用的英文版本。

`npm test` 已包含文档配对检查，因此以后新增英文文档时，如果没有对应的中文副本，测试会失败。
